# Traqo MVP User Flow

## 1. Launch Application

The user opens the Traqo application.

↓

## 2. Authentication

The user can:

* Sign Up
* Login

After successful authentication, the user is redirected to the Dashboard.

↓

## 3. Dashboard

The dashboard serves as the home screen and provides access to:

* Workout Plans
* Start Workout
* Workout History
* Profile (Basic)

↓

## 4. Workout Plans

The user can:

* Create a workout plan
* View existing workout plans
* Edit a workout plan
* Delete a workout plan

A workout plan contains one or more exercises.

↓

## 5. Start Workout

The user:

* Selects a workout plan
* Begins the workout session

For each exercise, the user records one or more sets.

Each set includes:

* Reps
* Weight
* Notes (Optional)

Each row represents one completed set.

↓

## 6. Finish Workout

When the workout is complete:

* The workout session is saved
* All exercises and recorded sets are stored
* The workout is added to the user's history
* Personal records (PRs) are updated if a new best performance is achieved

↓

## 7. Workout History

The user can:

* View all previous workouts
* Open a workout to see exercise details
* Review sets, reps, weights, and notes
* View workout date and duration

↓

## 8. Repeat

The user returns to the Dashboard to:

* Start another workout
* Manage workout plans
* Review workout history
* Continue tracking progress over time
